# 💧 솔라나 러그 데이터 전수 검증 & 카테고리

우리가 수집한 솔라나 토큰 **104,645개를 100% 온체인 스캔**하고, 그중 풀 주소 **63,671개를 DexScreener로 전량 검증**해 정확한 카테고리로 재분류했다.

**한 줄 요약**: 우리 "러그풀 풀"의 **94.6%가 유동성이 실제로 빠진 러그 확정**(온체인 사실). 오탐(정상 대형 풀) 0.2%는 제거했다.

---

## 1. 풀 vs 토큰 — 왜 구분해야 하나

- **토큰 mint** = 코인 자체의 신분증 주소
- **유동성 풀** = 그 코인을 SOL/USDC와 바꿔주는 "돈 웅덩이" 계정. 하나의 코인이 여러 풀(Raydium·Meteora·Orca)을 가질 수 있음
- **러그풀** = 사기꾼이 이 웅덩이에서 SOL을 통째로 빼감 → 팔 상대가 사라져 코인 가치 0

→ 토큰 mint는 "러그 **가능성**"(권한·홀더집중)을, 풀은 "러그 **실행**"(유동성 제거)을 본다. 풀 검증이 러그를 **온체인 사실로 확증**하는 이유.

## 2. 전체 온체인 스캔 (104,645개, getMultipleAccounts)

| 계정 유형 | 개수 | 비율 |
|---|---:|---:|
| 🪙 토큰 mint (SPL 39,701 + Token-2022 989) | 40,690 | 38.9% |
| 💧 유동성 풀 (Raydium 25,720 · Meteora 20,974 · Orca 7,894 · 기타 AMM) | 63,671 | 60.8% |
| 지갑/컨트랙트/닫힘 | 284 | 0.3% |

**토큰 mint 40,690개 권한 상태**: mint authority 활성 25.0%(무한발행 가능) · freeze authority 활성 12.0%(허니팟 가능) · Token-2022 2.4%.

## 3. 풀 검증 (DexScreener 전량, 63,671개)

| 판정 | 개수 | 비율 | 의미 |
|---|---:|---:|---|
| **rug_completed** | 60,246 | **94.6%** | 유동성 완전 제거 = 러그 실행 확정 |
| scam_pool_active | 3,270 | 5.1% | 유동성 남음 (진행중/방치된 러그) |
| **false_positive_major** | 155 | 0.2% | SOL/USDC 정상 대형 풀 (**제거**) |

**오탐 155개 예시**: $2,500만(Orca) · $1,420만(Raydium) · $671만(Orca) — 명백한 정상 풀이 SolRPDS에 오라벨된 것. `solana/verify/false_positive_pools.txt`로 build_wallets가 영구 제외.

**풀 → 스캠 코인 역추출**: 유동성 남은 풀에서 유니크 스캠 코인 1,729개 식별(한 코인당 평균 1.91 풀, 다중상장 537개). 러그 완료 풀 대부분은 계정이 닫혀 코인 미상(정상 — 이미 사라짐).

## 4. 사전 탐지 — "러그를 미리 잡을 수 있는가"

**답: 된다.** 우리 데이터 실측 + 학술 연구가 일치:

| 시그널 | 러그 검출 | 정상 오탐 | 근거 |
|---|---:|---:|---|
| **단일홀더 ≥ 90%** | 69% | **3.4%** | 우리 조기감지 연구 ([README](README.md)) |
| top10 홀더 ≥ 90% | 91% | — | 메커니즘 분석 |
| 단일홀더≥90% AND 유동성≤$100 | 23% | **0.6%** | 복합 룰 |

**핵심**: 러그의 본질은 "물량 독점"(top10≥90%가 러그의 91%). 권한 남용(무한발행·허니팟)은 pump.fun 자동 포기로 거의 소멸(mint 100%/freeze 99.9% 포기). 학술(Catching the Rug)은 **첫 5분 거래만으로 XGBoost가 러그 예측**(MCC 0.395).

### 실시간 사전 탐지 스코어링 (우리 데이터 기반 제안)
새 토큰이 나왔을 때 온체인 조회로:
1. freeze/mint authority 미포기 → 즉시 위험
2. top10 홀더 ≥ 90% (커브 PDA 제외) → 러그 91% 신호
3. 인사이더 펀딩 클러스터 (공통 SOL 펀더)
4. 유동성 ≤ $100 & LP 미소각
5. creator 과거 러그 이력

→ 이 중 2개+ 겹치면 고위험. 우리 데이터셋이 이 룰의 **학습·검증 근거**.
